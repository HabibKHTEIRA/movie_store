# Movie Store

## Lancement du Projet

### Backend (Spring Boot)

```bash
cd backend
mvn spring-boot:run
```

Le serveur backend démarre sur `http://localhost:8080`.

### Frontend (Angular)

```bash
cd frontend
npm start
```

L'application est accessible sur `http://localhost:4200`.
